# Release presentation

Use the verification report as evidence for the release brief. Preserve the reported test result, remaining checks and any caveats. State what still needs confirmation when the report leaves the release decision open.

Use the sections in [the release outline template](assets/outline.json) to organize the draft. Present the draft for editing and use the approved outline for the presentation.
