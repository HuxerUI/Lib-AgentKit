## Windows 原生工具

GanWork 使用现有工具审批确认 PowerShell 命令、搜索词和页面地址。PowerShell 默认在当前项目目录运行，独立对话使用任务专属目录。命令以当前 Windows 账户运行，审批会显示命令和工作目录。

启动 GanWork 前设置 `GANWORK_WEB_SEARCH_API_KEY` 可启用 Brave 网页搜索。兼容的 HTTPS 服务可通过 `GANWORK_WEB_SEARCH_ENDPOINT` 指定完整搜索端点。页面读取可直接打开 HTTP(S) 文本内容，包含重定向的请求需要另行审批目标地址。

## 会话时间线设计

同一段连续工作在对话中显示为一条可展开的摘要。助手发出正文就结束前一段，接下来的工具调用在正文后另起一组。一个 Run 可以有多组，正文、审批和产物各自保留原来的时间位置。

折叠时显示当前操作或已完成的操作计数，例如「正在检查项目」和「读取 3 个文件 · 搜索 2 次」。展开后按原顺序显示文件路径、命令、退出状态、逐文件差异和工具输出。待审批、失败和结果待核对的位置在折叠状态下也可见。

活跃分组使用一个小型进度指示器，固定占位。等待审批时换成静态状态，正文流式显示时由正文自身提供反馈。计时采用已经记录的 Run 起止时间。动画只更新当前分组的绘制，展开和收起沿用历史列表的阅读锚点。

GanWork 从现有 `SessionEvent` 和快照构建分组。首个工具调用 ID 作为稳定的视图标识，后续事件在同一位置更新分组，恢复时按已提交的消息和工具顺序重建。先验收「操作组 → 正文 → 操作组 → 结论」、等待审批、展开看 Diff，以及流式输出和重启时的阅读位置。

参考 [Codex 的连续命令分组](https://github.com/openai/codex/pull/38921) 和 [Claude Code 的详细时间线与逐轮 Diff](https://support.claude.com/en/articles/14553413-claude-code-cheatsheet)。

## 演示助手

普通演示请求直接生成会话内可预览的 PPTX，模型推断受众、风格和篇幅并选择每页版式。发送前选择「先审阅大纲」可以先编辑大纲。审阅卡片打开独立页面，返回后仍可继续读取对话。导出由产物页发起，按已有权限处理。固定验收条件、委派和分叉比较沿用原有确认流程。

对话在等待输入或审阅时提供「停止并删除对话」。确认后停止当时的 Run，等它结束再删除会话。

模型设置可选择已保存的生图端点并填写图像生成模型 ID。端点需支持 OpenAI 兼容的 `/images/generations`，并返回 Base64 编码的 PNG 或 JPEG。配图与图像理解分开设置，生成的图片随暂存 PPTX 保存。

图表使用已核对的数据集或用户提供的数据。在请求里写下 `Source: https://...` 或「来源：https://...」，再附上两列 Markdown 表格，即可使用自己的类别和数值。每张图表均有来源链接和内嵌数据工作簿。

导出预览和产物审阅使用暂存 PPTX 的版式、文本、图片和图表数据，并以 16:9 显示整页。卡片、流程节点和连接箭头是 PowerPoint 可编辑形状。翻页使用快速淡入，流程节点按顺序入场。导出审批绑定已暂存的产物版本和文件名。
